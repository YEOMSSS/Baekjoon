value를 소수점 둘째 자리에서 반올림해서 f-string 방식으로 출력

## 보충 설명과 예시

서식 지정자로 소수 자릿수를 맞춘다.
```python
value = 3.14159
print(f"{value:.2f}")  # 3.14
```
