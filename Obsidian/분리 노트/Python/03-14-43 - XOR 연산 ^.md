a ^ b는 a와 b가 같으면 0, 다르면 1을 반환한다.  
2진수에서 bit ^= 1을 사용하면 bit가 0이면 1, 1이면 0을 반환하여 토글효과를 준다.

## 보충 설명과 예시

XOR은 같은 비트를 0, 다른 비트를 1로 만들어 토글에 쓴다.
```python
bit = 0
bit ^= 1
print(bit)  # 1
```
