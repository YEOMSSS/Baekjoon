딕셔너리에서 key와 value중 value만 모아 리스트처럼 동작하는 뷰 객체로 만든다.

## 보충 설명과 예시

값만 순회할 때는 `values()` 뷰를 그대로 사용하면 된다.
```python
d = {'a': 3, 'b': 5}
print(sum(d.values()))  # 8
```
