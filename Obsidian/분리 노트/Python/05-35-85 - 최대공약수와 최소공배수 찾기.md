# 최대공약수와 최소공배수 찾기

원문 사본: [[Obsidian/원본 - Python README]]

최대공약수(a, b) x 최소공배수(a, b) = a x b 이다.  
math.gcd(a, b) 는 최대공약수를 찾는다.  
math.lcm(a, b) 는 최소공배수를 찾는다.

- 유클리드 호제법  
  a와 b의 대소에 상관없이 a, b = b, a % b 를 반복해서 b가 0일 때 a가 최대공약수이다.

## 보충 설명과 예시

`gcd`와 `lcm`을 쓰면 유클리드 호제법을 직접 구현하지 않아도 된다.
```python
from math import gcd, lcm
print(gcd(12, 18), lcm(12, 18))
```
