반환값이 없다. 그냥 따로 써주면 list를 유니코드 기준 오름차순으로 정렬한다.

## 보충 설명과 예시

`sort()`는 원본을 바꾸고 반환값은 없다.
```python
a = [3, 1, 2]
a.sort()
print(a)  # [1, 2, 3]
```
