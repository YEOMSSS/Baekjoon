10진수 -> 2진수 bin(255)[2:] # '11111111'  
10진수 -> 8진수 oct(255)[2:] # '377'  
10진수 -> 16진수 hex(255)[2:] # 'ff'

## 보충 설명과 예시

문자열 진법 변환과 출력 진법 변환은 각각 `int`, `bin` 등을 쓴다.
```python
print(int('101', 2), hex(255))
```
