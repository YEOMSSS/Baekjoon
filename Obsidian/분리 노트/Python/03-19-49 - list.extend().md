list.append()와 달리 리스트를 풀어서 하나씩 집어넣는다. 병합느낌.

## 보충 설명과 예시

`extend`는 iterable의 원소를 하나씩 이어 붙인다.
```python
a = [1, 2]
a.extend([3, 4])
print(a)
```
