# 올림 계산 (math.ceil(a / b)의 정수형 풀이)

어떤 수 a를 b로 나눌 때, 나머지가 생기면 몫에 +1을 해야 하는 경우  
(a + b - 1) // b 를 하면 올림한 몫을 구할 수 있다.

## 보충 설명과 예시

양의 정수 나눗셈의 올림은 `(a + b - 1) // b`로 구한다.
```python
a, b = 10, 3
print((a + b - 1) // b)  # 4
```
