상태 플래그는 프로그램이 현재 어떤 상태(모드)에 있는지를 표시하는 변수다.  
이 값을 바꾸면서 흐름이나 동작 방식을 다르게 제어할 수 있다.

## 보충 설명과 예시

불리언이나 작은 정수로 현재 모드를 나타내면 흐름을 단순하게 만들 수 있다.
```python
is_open = False
is_open = True  # 상태 전환
```
