# dict.get(key, default)

원문 사본: [[Obsidian/원본 - Python README]]

dict[key]는 key가 존재하지 않으면 keyError가 나지만,  
dict.get(key, default)는 default를 반환한다. default가 없다면 None을 반환한다.

## 보충 설명과 예시

없는 키도 안전하게 기본값으로 읽을 수 있다.
```python
count = {'A': 2}
print(count.get('B', 0))  # 0
```
