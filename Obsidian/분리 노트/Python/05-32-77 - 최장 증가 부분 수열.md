LIS: Longest Increasing Subsequence

## 보충 설명과 예시

LIS 길이만 구할 때는 `bisect_left`로 각 길이의 최소 끝값을 관리한다.
```python
from bisect import bisect_left
tails = []
for x in [10, 20, 10, 30]:
    i = bisect_left(tails, x)
    if i == len(tails): tails.append(x)
    else: tails[i] = x
```
