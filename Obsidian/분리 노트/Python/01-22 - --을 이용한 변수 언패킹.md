# \*을 이용한 변수 언패킹

원문 사본: [[Obsidian/원본 - Python README]]

    a, *b = [10, 20, 30]
    a = 10, b = [20, 30]

    *a, b = [10, 20, 30]
    a = [10, 20], b = 30

    a, *b, c = [10, 20, 30, 40]
    a = 10, b = [20, 30], c = 40

## 보충 설명과 예시

별표 언패킹은 앞·뒤 일부를 분리할 때 유용하다.
```python
first, *middle, last = [1, 2, 3, 4]
print(first, middle, last)
```
