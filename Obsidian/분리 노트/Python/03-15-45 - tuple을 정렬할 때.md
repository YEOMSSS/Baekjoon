sorted((X, Y, Z))는 작동하지 않는다.  
tuple(sorted([X, Y, Z]))를 사용하도록 하자.

## 보충 설명과 예시

여러 값을 정렬한 뒤 튜플로 다시 묶는다.
```python
x, y, z = 3, 1, 2
print(tuple(sorted((x, y, z))))
```
