그래프 한개라고 줘 놓고는 여러 component로 뚝뚝 떨어진 그래프들이 있을 수 있는데,  
1-2-5-1 3-4-6 처럼 나누어진 각각의 그래프를 연결 요소라고 한다.

## 보충 설명과 예시

아직 방문하지 않은 정점에서 탐색을 새로 시작한 횟수가 연결 요소 수다.
```python
components = 0
for v in range(1, n + 1):
    if not visited[v]:
        components += 1
```
