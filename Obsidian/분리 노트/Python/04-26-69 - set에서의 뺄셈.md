list + list는 가능하지만, list - list는 불가능하다.  
요소끼리 빼고 싶다면 set으로 변환하여 set - set을 하면 된다.

## 보충 설명과 예시

집합 차집합은 한 컨테이너에만 있는 원소를 구한다.
```python
print({1, 2, 3} - {2, 4})  # {1, 3}
```
