deque는 연결리스트 베이스로 만들어져 있어서 슬라이싱이 불가능하다.  
deque.reverse()를 통해 뒤집을 수 있다. 또는 1회성으로 reversed(deque)도 가능하다.

## 보충 설명과 예시

양끝에서 꺼내는 BFS 큐에는 `deque`가 적합하다.
```python
from collections import deque
q = deque([1])
q.append(2)
print(q.popleft())  # 1
```
