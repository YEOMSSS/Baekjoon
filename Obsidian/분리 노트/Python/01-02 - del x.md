del은 만능이다. index나 key 개념의 것을 전부 삭제할 수 있다. set에는 못쓴다는거지.  
변수를 지워버릴수도 있다. 바인딩 삭제 개념.

## 보충 설명과 예시

`del`은 이름이 가리키는 바인딩이나 컨테이너의 항목을 제거한다.
```python
a = [10, 20, 30]
del a[1]
print(a)  # [10, 30]
```
