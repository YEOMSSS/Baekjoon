원문 사본: [[Obsidian/원본 - Python README]]

- char.isupper() : 대문자인지 판정
- char.islower() : 소문자인지 판정
- char.isalpha() : 알파벳인지 판정

## 보충 설명과 예시

문자열 메서드로 대·소문자와 알파벳 여부를 검사한다.
```python
ch = 'A'
print(ch.isupper(), ch.isalpha())
```
