간선의 가중치가 0 또는 1인 임의의 정점 u에 BFS를 실행해봅시다.

## 보충 설명과 예시

가중치가 0·1뿐이면 0 간선은 덱의 앞에 넣어 다익스트라보다 단순하게 처리한다.
```python
from collections import deque
# 0 비용: appendleft, 1 비용: append
```
