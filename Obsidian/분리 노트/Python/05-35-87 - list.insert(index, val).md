insert(2, 3) → 인덱스 2에 3을 넣고, 기존 요소는 오른쪽으로 밀린다.

## 보충 설명과 예시

`insert(i, x)`는 i번째 위치에 넣고 뒤 원소를 민다.
```python
a = [1, 3]
a.insert(1, 2)
print(a)
```
