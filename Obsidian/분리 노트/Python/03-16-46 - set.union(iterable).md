set에 있는 합집합 만들기 코드.  
리스트의 +연산 느낌인데, 모든 iterable을 커버 가능하다.

## 보충 설명과 예시

여러 집합·iterable의 합집합을 만들 수 있다.
```python
print({1, 2}.union([2, 3]))  # {1, 2, 3}
```
