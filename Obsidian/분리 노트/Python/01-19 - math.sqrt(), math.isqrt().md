제곱근을 반환한다. 차이는 isqrt는 소수점 이하를 자른다.  
isqrt는 int(sqrt)와 달리 부동소수점 오차를 걱정할 필요가 없어 효율적. 아예 int 형태로 반환함  
큰 수의 제곱근의 정수 부분만 정확하게 필요한 경우 주로 사용한다고 생각하면 된다.

## 보충 설명과 예시

정수 제곱근은 부동소수점 오차 없이 바닥값을 준다.
```python
from math import isqrt
print(isqrt(17))  # 4
```
