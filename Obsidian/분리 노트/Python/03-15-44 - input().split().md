자동으로 리스트 형태로 저장된다.  
list(map(int, input().split()))에서 list를 쓰는 이유는 map 때문일 뿐이다.

## 보충 설명과 예시

공백 입력을 숫자로 바꿀 때는 `map`을 바로 순회할 수도 있다.
```python
a, b = map(int, '10 20'.split())
print(a + b)
```
