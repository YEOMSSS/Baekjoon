**여러 iterable(리스트 등)**을 병렬로 묶어서 쌍을 만들어주는 함수

    a = ['A', 'B', 'C']
    b = [9, 8, 7]

    z = zip(a, b)
    print(list(z))  # [('A', 9), ('B', 8), ('C', 7)]

## 보충 설명과 예시

여러 iterable을 같은 인덱스끼리 묶는다.
```python
for name, score in zip(['A', 'B'], [90, 80]):
    print(name, score)
```
