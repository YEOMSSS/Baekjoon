# '0'으로 숫자 문자 변환하기

---
tags: [baekjoon, c, algorithm]
---

⬆ 상위 노트: [[Obsidian/분리 노트/C/03 - 00. 기타]]

원문 사본: [[Obsidian/원본 - C README]]

1. 문자 → 숫자 변환할 때 (빼기)
   char c = '7';
   int n = c - '0'; // n = 7

'7'의 아스키 코드 = 55
'0'의 아스키 코드 = 48

55 - 48 = 7
👉 문자 '7'을 정수 7로 바꿀 때는 - '0'.

2. 숫자 → 문자 변환할 때 (더하기)
   int n = 7;
   char c = '0' + n; // c = '7'

'0' = 48

48 + 7 = 55 → 아스키 코드 55는 '7'
👉 정수 7을 문자 '7'로 바꿀 때는 + '0'

## 보충 설명과 예시

핵심 동작만 확인하는 짧은 예시입니다.
```c
char ch = '7';
int digit = ch - '0';
```
