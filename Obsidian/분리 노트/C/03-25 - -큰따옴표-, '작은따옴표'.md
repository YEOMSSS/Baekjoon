"큰따옴표"는 char배열. 문자열이다. 끝에 \0이 붙는 문자열이다.  
'작은따옴표'는 그냥 char. 문자. 1바이트 정수다. 끝에 \0이 붙지 않는 한 글자다.

char c = 'a'; // 문자 하나 (ASCII 97)  
char s[] = "a"; // 문자 배열 {'a','\0'}
