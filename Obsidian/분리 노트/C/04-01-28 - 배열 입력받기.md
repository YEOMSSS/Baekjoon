    int nums[3], temp;
    for (int i = 0; i < 3; i++){
        scanf("%d", nums + i);
    }

&nums[i] 로 직접 주소를 입력할 수도 있다. nums + i 역시 같은 의미다.

## 보충 설명과 예시

핵심 동작만 확인하는 짧은 예시입니다.
```c
for (int i = 0; i < n; i++) scanf("%d", &a[i]);
```
