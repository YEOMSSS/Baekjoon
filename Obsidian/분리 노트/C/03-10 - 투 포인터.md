두 개의 정렬된 배열을 합쳐 정렬하려면 배열마다 0에서 시작하는 포인터를 만들어주고,  
포인터가 가리키는 값이 작은 걸 출력 후 그 포인터를 한 칸 앞으로 보내는 것을 반복하는 것이다.

## 보충 설명과 예시

핵심 동작만 확인하는 짧은 예시입니다.
```c
int l = 0, r = n - 1;
while (l < r) {
    if (a[l] + a[r] < target) l++;
    else r--;
}
```
