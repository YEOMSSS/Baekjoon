`printf("%d", (X < Y) ? X : Y)` 이런 느낌  
조건식 ? 값1 : 값2  
조건식이 참(≠0)이면 → 값1 반환  
조건식이 거짓(=0)이면 → 값2 반환

## 보충 설명과 예시

핵심 동작만 확인하는 짧은 예시입니다.
```c
int mx = a > b ? a : b;
```
