## 보충 설명과 예시

백준에서는 iostream과 C stdio의 동기화를 끄고 tie를 풀면 입력이 빨라진다.
```cpp
#include <iostream>

int main() {
    std::ios::sync_with_stdio(false);
    std::cin.tie(nullptr);
}
```
