- Python 기본기: `f-string`, `defaultdict`, `Counter`, `accumulate`, `bisect`
- 자료구조: `deque`, `heapq`, `set`, `dict`, 우선순위 큐
- 탐색: DFS, BFS, 백트래킹, 0-1 BFS
- 최적화: 투 포인터, 누적합, 이분 탐색, 중간에서 만나기

- DP: 메모이제이션과 타뷸레이션
